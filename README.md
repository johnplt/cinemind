# cinemind
Cinéma, IA &amp; Impact Social (CineMind / Cultural Bias Explorer) Un observatoire en ligne qui analyse la représentation des problématiques sociales (santé mentale, minorités, stéréotypes) dans les scénarios de films ou les critiques de cinéma à travers le temps.

# 1. Initialiser la structure uv dans le dossier existant
uv init --bare

# 2. Ajouter les dépendances de base
uv add requests python-dotenv psycopg2-binary pandas
